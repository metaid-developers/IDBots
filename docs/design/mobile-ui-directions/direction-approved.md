## Approved iteration scope

- Keep Direction D's layout and interaction model.
- Preserve the centered Bot identity in the top navigation and the absence of repeated Bot avatars inside the conversation.
- Preserve the composer capsule and bottom navigation.
- Preserve the expanded task and itinerary document presentations.
- Develop and review a complete light appearance alongside the existing dark appearance.
- Do not change production PWA or native-shell code in this design iteration.
