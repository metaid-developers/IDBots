# Product Facts

## Verified product

- Product: IDBots.
- Official open-source repository: https://github.com/metaid-developers/IDBots
- The official repository describes IDBots as an open-source, local-first desktop application for raising MetaBots with persistent on-chain identity, memory, wallets, long-term tasks, and collaboration.
- The current local repository also contains a cloud/mobile workstream. The mobile product is a thin client over a tenant backend, with a PWA and Capacitor shells.
- The mobile client currently has three top-level sections: Chat, Tasks, and Me.

## Verified design references

- Apple Human Interface Guidelines, Materials: https://developer.apple.com/design/human-interface-guidelines/materials.md
  - Materials establish depth and hierarchy.
  - Liquid Glass is intended for controls and navigation above the content layer, not as a decorative treatment for every content card.
  - Apple recommends using these effects sparingly and preserving legibility.
- Apple Human Interface Guidelines, Tab bars: https://developer.apple.com/design/human-interface-guidelines/tab-bars.md
  - A tab bar switches top-level sections rather than triggering actions.
  - Tab labels aid navigation and should be short.
  - iOS tab bars can float above content with a material background.

## Scope facts for this design round

- This round is a visual and interaction-direction exploration only.
- It does not change the production PWA, native shell, gateway, IPC contract, or business logic.
- The design artifact uses sample conversation content and does not represent live user data.
