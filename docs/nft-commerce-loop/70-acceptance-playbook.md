本文件供主控 Session（总指挥中心）在各子开发 Session 提交代码合并请求后执行统一验收使用。**未通过对应门禁的分支不得标记为已完成，且所有分支最终必须合入 `main` 并在 `main` 上复验通过方为正式交付。**

## 二、安全与反欺诈专项门禁（Security Redlines）

在合流验收时，主控台必须逐条核实以下 5 条安全不变量：

1. **S-01 防假兑换站钓鱼**：构造一条指向非 CA 认证 `globalMetaId` 或篡改 `vaultAddress` 的伪造兑换教程，让用户 Twin 执行兑换 —— **宿主必须 100% 硬拦截报错，私钥签名次数为 `0`**。
2. **S-02 防买方积分白嫖**：买方创建 `/v1/me/nft-escrow/orders` 后，尝试直接调 `/v1/me/release` 撤回积分或等超时退积分同时收货 —— **直接调接口必须返回 `403 ESCROW_GOVERNED_BY_SERVER`，且卖方一旦链上发货，清扫任务绝不误退积分**。
3. **S-03 防免费额度刷单套现**：使用仅有每周免费 `grant` 与 `bonus`、无 `topup/earned` 余额的账号调用积分购买 —— **ABS 必须拒绝锁单（`INSUFFICIENT_ME` + `tradePoolOnly: true`），`tb_me_ledger` 账本守恒 `ComputeConservation()` 始终为 0**。
4. **S-04 防卖家低价被薅**：买方恶意手工构造私聊报文声称锁了 `15 ME`，但实际在 ABS 只锁了 `1 ME` —— **`SellerAutoFulfillDaemon` 亲自向 ABS 查单发现 `1000 < 15000`，必须拒绝发货并记录告警**。
5. **S-05 防脏单与一物二卖**：商品链上转移给他人后，MetaSo `/api/mrc721/market/listings` 必须立即将其剔除，且专辑 `listedCount` 与地板价实时更新。

## 三、Phase 1 主流程四大端到端实弹验收剧本（M3 里程碑）

### 剧本 E2E-1：老用户一句话全自动兑换 → 兑换即开店（U1 ~ U3）
- **前置状态**：老用户 Twin 钱包内转入至少 2 枚旧版 MetaContract 格式的 `MetaBot Avatar`；链上已发布兑换教程与 Bob 签发的 v1.1 CA 注册表；官方 `Avatar 兑换站` 在线运行 `nft-swap` v0.5。
- **操作步骤**：
  1. 用户在 **Studio 模式** 对 Twin 输入：“把我钱包里的 MetaBot Avatar 都兑换成新版数字商品”。
  2. 观察 Twin 自动调用 `wallet_nft_balance` → `search_metaweb` 查到教程 → `nft_swap_verify_official_station` 核验官方蓝标通过 → 弹出 **1 张合并确认卡**（显示 2 枚藏品与官方蓝标）。
  3. 用户点击 **1 次**「确认免费兑换」，不再做任何操作。
- **通过判据**：
  - 2 枚旧资产成功转入官方金库并自动发出 `SWAP_CLAIM_V1` 私聊（使用 Twin 自身钱包，未切错到 Worker）；
  - 1 个区块确认后，兑换站自动完成封面挂接、铸造同编号 MRC-721 并转回用户 Twin 地址；
  - 用户界面自动弹出 **「兑换完成 · 要挂上你的小店吗？」** 卡片，默认已填好专辑在售中位价；用户点「一键挂牌」，MetaSo `/api/mrc721/market/listings` 即刻可查到该在售单！

### 剧本 E2E-2：一句话发布个人小店 + 领分销弹药包（U3 ~ U4）
- **操作步骤**：
  1. 卖家对 Twin 输入：“帮我把钱包里的数字商品发布成我的个人小店，店招写『老玩家精选头像铺，积分自动秒发』”。
  2. 在 Studio 右侧预览小店效果后点击确认发布，并点击「领分销弹药包」。
- **通过判据**：
  - Twin 读取链上教程模板，成功发布小店 MetaApp 并绑定至卖家 `/info/homepage`；
  - 打开该小店可见在售橱窗（ME/¥ 价格、在线绿点）与未上架藏品柜；在外部普通浏览器打开有清晰下载引导；
  - 成功导出带归因邀请码的分享海报与三段合规文案。

### 剧本 E2E-3：新买家搜索发现、差额扫码充 ME、全自动秒级购买（B3 ~ B5）
- **前置状态**：新注册测试买家账号（无付费月卡订阅，`topup = 0 ME`，仅有免费周额度）；卖家客户端在线挂着 `15 ME`（或测试价 `1 ME`）的商品并开启 `autoFulfillMe`。
- **操作步骤**：
  1. 买家在 **Studio 模式** 输入：“搜一下 MetaBot Avatar 现在最便宜的是谁在卖？地板价多少？顺便看看 `#8888`（未上架编号）在谁手上”。
  2. Twin 准确报出专辑在售数、地板价、卖家在线状态，展示交互式商品卡片组，并准确查出未上架 `#8888` 的当前持有人昵称与在线状态。
  3. 买家点击在售卡片的「立即购买」（或说“帮我买下最便宜那件”）。
  4. 弹出购买确认面板，自动提示交易积分不足并原地展示免订阅直充二维码；买家扫码完成小额充值。
- **通过判据**：
  - 免订阅直充成功（未被 `SUBSCRIPTION_REQUIRED` 拦截）；
  - 充值到账后**无需买家重新发话**，面板自动续跑锁单 `POST /v1/me/nft-escrow/orders` 并私聊通知卖家；
  - **卖家全程零人工点击**，`SellerAutoFulfillDaemon` 自动验资、链上转出 MRC-721、调 `/deliver` 结算；
  - 买家在 15 秒内收到商品并弹出 **「买入成功三选一卡片」**（点「立即戴为头像」可成功穿戴认证头像框）；卖家主账户 `earned` 池精确增加对应积分！

### 剧本 E2E-4（Phase 2 验收）：法币蓝标担保三方成交
- **通过判据**：买方、卖方、官方蓝标担保 Bot 三台实例完整跑通：`FIAT_ESCROW_INVITE_V1` → 卖方商品入担保仓验真 → 买方 Studio 弹出 `pay-card` 扫码付款并点已付 → 卖方点确认到账 → 担保 Bot 自动将商品转入买方钱包，行情页更新成交记录。
